# Latent Probing for Toxicity

This repository is a minimal public publication scaffold for a planned software project around latent toxicity probing in a frozen language model.

The current public scope is intentionally narrow:

- [PROJECT_PROPOSAL.md](./PROJECT_PROPOSAL.md)
- [AUDIT_LOG.md](./AUDIT_LOG.md)
- repository structure placeholders for future JOSS-oriented work

Large local research assets, notebooks, rendered media, course materials, and background papers are intentionally excluded from version control and publication.

## Status

Proposal stage only. No production software, benchmark claims, or moderation claims are published in this repository at this stage.

## Publication intent

This repository exists to establish a clean public audit trail for the software proposal and subsequent repository-level decisions.

## Current repository structure

- `PROJECT_PROPOSAL.md` — software proposal and scope statement
- `AUDIT_LOG.md` — running audit log for publication and curation decisions
- `paper/` — reserved for future JOSS paper assets
- `artifacts/` — reserved for future release-safe artifacts
